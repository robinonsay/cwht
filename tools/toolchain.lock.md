### 1.1 Sanity checks (charter §8; CM plan §9.2 step 2)

One row per class A or B tool. The single fixture root is `tools/tests/fixtures/`: each fixture is committed under `tools/tests/fixtures/<tool>/` with its expected output. Python tools are exercised by named test modules run from the repository root; each row names its own modules and test classes, so that one tool's result never depends on another tool's suite or on repository content. Full detail lives in the `TV-NNN` record.
